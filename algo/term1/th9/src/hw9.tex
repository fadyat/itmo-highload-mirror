\section{DFS}

\subsection{Домашнее задание}
\begin{enumerate}
  \item
    Пусть дано дерево $T = \langle V, E \rangle$. Для каждого ребра вычислить, сколько
    простых путей проходит через него. $\O(|V| + |E|)$.

  \item
    Корневое дерево $T$ на $V$ вершинах задается массивом
    из $V$ элементов. Все вершины пронумерованы. Для каждой вершины
    в массиве указан его родитель.  Для корня $r$ значение в массиве
    равно -1. Требуется определить, как будет выглядеть новое представление
    дерева, если корень $r$ сменить на корень $q$. Разрешается использовать
    $\O(1)$ дополнительной памяти. Менять массив можно. Время $\O(V)$.

  \item
    За $\O(|V| + |E|)$ найдите в \textbf{неорграфе}:
    \begin{enumerate}
      \item все \textbf{ребра}, через которые проходит любой путь $a \leadsto b$.
      \item все \textbf{вершины}, через которые проходит любой путь $a \leadsto b$.
    \end{enumerate}

  \item
    Дано дерево $T = \langle V, E \rangle$.
    \begin{enumerate}
      \item
        Найдите центроид дерева --- вершину $c$, для которой минимальна \\
        $\sum_{v \in V} dist(v, c)$. $\O(|V|)$.

      \item
        Найдите 2-центроид дерева --- пару вершин $(a, b)$, для которой минимальна \\
        $\sum_{v \in V}\min(dist(v, a), dist(v, b))$). $\O(|V|^2)$.
    \end{enumerate}

\subsection*{Дополнительные задачи}

  \item
    Для заданного ориентированного графа $G = \langle V, E \rangle$ посчитать
    минимальное число ребер, которые нужно добавить в граф, чтобы
    он стал сильно связным. Время $\O(|V|^3)$.

   \item
    Дано дерево $T = \langle V, E \rangle$. Найдите 2-центроид за $\O(|V|)$.

\end{enumerate}

\section{Решения}

\begin{enumerate}

\item

Чтобы вычислить, сколько простых путей проходит через каждое ребро дерева,
можно воспользоваться свойствами деревьев, где любое ребро является мостом.

Запустим обход в глубину из корневой вершины и будем запоминать размер нижнего поддерева
для каждой вершины.

$size[v] = 1 + \sum_{u \in children[v]} size[u]$.


После того как размеры поддеревьев вычислены, переходим к обработке каждого ребра
$(u, v)$. Любое ребро делит дерево на два поддерева: одно с корнем в вершине $v$, содержащее
$size[v]$ вершин, и другое, содержащее оставшиеся $|V| - size[v]$ вершин.

Количество простых путей, проходящих через это ребро, равно произведению чисел вершин в этих двух поддеревьях, то есть
$size[v] \cdot (|V| - size[v])$.
Это справедливо, так как любая вершина из первого поддерева может соединяться с любой вершиной
из второго поддерева, образуя уникальный простой путь через ребро.

\includegraphics[width=0.5\textwidth]{example.png}

Таким образом, общее время работы упирается во время работы DFS, то есть $\O(|V| + |E|)$.

\item

Пусть $p[v]$ --- родитель вершины $v$ в текущем представлении дерева.
Тогда, для изменения корня с $r$ на $q$ достаточно инвертировать ребра на пути.
Для этого запустимся из $q$ и будем запоминать родителя прошлой вершины, пока не дойдем до $r$.

\begin{lstlisting}[language=C++]
void change_root(vector<int>& p, int q) {
    int current = q;
    int previos_parent = -1;

    while (current != -1) {
        int next = p[current];
        p[current] = previos_parent;
        previos_parent = current;
        current = next;
    }
}
\end{lstlisting}

В худшем случае пока мы не достигли старого корня, мы пройдем по всем вершинам дерева.
Следовательно, время работы --- $\O(V)$.

\item

    \begin{enumerate}

    \item

        Если все пути $a \leadsto b$ проходят через ребро $(u, v)$, то это означает, что
        это ребро является мостом между двумя компонентами реберной двусвязности, содержащими
        вершины $a$ и $b$.

        Поэтому, чтобы найти все такие ребра, достаточно найти все мосты в графе. \newline
        \url{http://e-maxx.ru/algo/bridge_searching}

        Далее пройдемся по всем ребрам графа еще одним поиском в глубину и проверим, что
        ребро содеожится в множестве мостов.

        Итоговое время работы --- $\O(|V| + |E|)$.

    \item

        Алгоритм действует аналогично предыдущему пункту, только теперь мы используем
        вершинную двусвязность. Найдем все точки сочленения в графе и пройдемся по всем вершинам
        графа, проверяя, что вершина является точкой сочленения. \newline
        \url{http://e-maxx.ru/algo/cutpoints}

        Итоговое время работы --- $\O(|V| + |E|)$.

    \end{enumerate}
