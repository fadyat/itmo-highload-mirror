### Задание 3: Кто-то сказал рекурсия?

#### Часть 1: Бесконечный цикл?

На лекции мы упоминали, что в Scala в `Monad` добавили один специфичный метод, и у вас появился вопрос, а зачем он
нужен? Давайте поймём это на практике! Исправьте метод `retry` так чтобы тест проходил (сейчас падает со
`StackOverflowException`).

```scala
def retry[F[_] : Monad, A](start: A)(f: A => F[A]): F[A] =
  f(start).flatMap(retry(_)(f))
```

Подсказка: Вы можете использовать `Monad[F].tailRecM` (либо что-то ещё - например цикл на `Monad`, но оно в конечном
счёте использует под капотом `Monad[F].tailRecM`, поэтому предлагаем использовать только `Monad[F].tailRecM` )

#### Часть 2: Продолжить или не продолжить, вот в чём вопрос

Давайте повторим это упражнение, только теперь признаком для повтора будет ошибка. Исправьте реализацию метода `retry`
так чтобы прошли тесты.

```scala
implicit class RetrySyntax[F[_], A](self: => F[A]) {
  def retry(implicit monad: MonadError[F, _]): F[A] = {
    def loop: F[A] = monad.handleErrorWith(self)(_ => loop)

    loop
  }
}
```

### Задание 4: Monad

На последок простое задание, надо всего-лишь реализовать `MonadError` для `FailableFunction` (это `Function1`, который
может падать с ошибкой):

```scala
trait FailableFunction[-In, +Err, +Out] {
  def apply(in: In): Failable[Err, Out]
}

sealed trait Failable[+E, +A]

object Failable {
  final case class Success[+A](value: A) extends Failable[Nothing, A]

  final case class Failure[+E](error: E) extends Failable[E, Nothing]

  def fromEither[E, A](either: Either[E, A]): Failable[E, A] = either match {
    case Right(out) => Success(out)
    case Left(err)  => Failure(err)
  }
}
```

### Бонусное задание

Напомним, что на курсе действует система бонусных баллов (каждый бонусный балл - это абсолютный балл в системе БАРС); и
с этого ДЗ мы явно объявляем: что вы можете заработать бонусные баллы написав дополнительные тесты к ДЗ и получить
баллы пропорциональные количеству студентов у которых эти тесты упадут, по формуле
`bonus = Math.ceil(HW * (fail / total)) + Math.ceil(1 * (fail / total))` (где `HW` - количество баллов за ДЗ, `fail` -
количество студентов у кого упали тесты, `total` - общее студентов, кто сдал ДЗ).

Ограничения:

- Тесты надо предоставить до дедлайна по ДЗ;
- Баллы начисляются только за работы студентов которые уже сдали ДЗ на момент добавления доп тестов и получили баллы;
- Студентам кто уже сдал ДЗ, но у них упали доп тесты - необходимо исправить ДЗ (напомню, что вы всё ещё получаете 100%
  баллов за сдачу в срок дедлайн + 1 неделя);
- Тесты должны быть адекватные, и соответствовать заданию (за тесты вида `if (Random.nextInt() % 2 == 0) fail() else ok`
  будем снижать балл за ДЗ тому кто их предложил);

## Code Style:

Мы последовательно вводим список запрещенных механик, которыми нельзя пользоваться при написании кода, и рекомендаций по
code style. За нарушения мы оставляем за собой право **снижать оценку**.

* Переменные, классы и функции должны иметь осмысленные названия;
* Использовать `var` запрещается (используйте `val`);
* Использование `this` запрещается (используйте `self`, если надо);
* Использование `super` запрещается;
* Использование `null` запрещается (используйте `Option`);
* Использование `return` запрещается;
* Использование `System.<any function>` (например `System.exit`) запрещается;
* Использовать циклы запрещается (используйте `for comprehension`, `tailRec`, `tailRecM`);
* Использование java коллекций запрещается (используйте scala коллекции);
* Использование scala mutable коллекций запрещается (используйте scala immutable коллекции);
* Использовать `throw` запрещено;
* Использовать неявные преобразования запрещено;
* Касты или проверки на типы с помощью методов из Java вроде `asInstanceOf` запрещаются;
