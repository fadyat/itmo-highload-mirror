### Задание 3: Env

Библиотека `cats-effect` предоставляет typeclass для работы с переменными окружения:

```scala
trait Env[F[_]] {
  def get(name: String): F[Option[String]]

  def entries: F[Iterable[(String, String)]]
}
```

Вам предлагается написать свой typeclass для работы с переменными окружения расширив уже имеющийся новым функционалом,
а именно возможностью добавления в окружение новых переменных. В этом задании обойдёмся псевдо-добавлением новых
переменных окружения: вам не нужно делать системные вызовы для добавления переменных в окружение, вы должны хранить все
добавленные переменные локально и при вызове проверять есть ли значение локально, а только потом проверять внешние.

За вас уже написали определение, вам требуется только добавить реализацию.

```scala
trait LocalEnv[F[_]] extends Env[F] {
  def set(name: String, value: String): F[Unit]
}
```

Вам так же требуется добавить функцию для работы с консолью (`Application.consoleApplication`), она умеет обрабатывать
всего 3 команды:

* `exit` - выйти и успешно завершить программу;
* `set <key> <value>` - установить переменную окружения (локального); Вывод - `'<key>' '<value>'`;
* `get <key>` - получить переменную окружения; Вывод - `'<key>' '<value>'` если значение найдено и `Not found` иначе;
* В случае получения неизвестной команды - вывести в консоль `Unknown command` и ждать следующего пользовательского
  ввода.

Пример работы:

```text
> get HTTP_PORT
< Not found
> set HTTP_PORT 8080
< 'HTTP_PORT' '8080'
> get HTTP_PORT
< 'HTTP_PORT' '8080'
> set HTTP_PORT  80
< 'HTTP_PORT' '80'
> get HTTP_PORT
< 'HTTP_PORT' '80'
> get LANG
< 'LANG' 'C.UTF-8'
> set LANG C.UTF-16
< 'LANG' 'C.UTF-16'
> get LANG
< 'LANG' 'C.UTF-16'
> exit
```

### Задание 4: Fiber Boss

На одной из прошлых практик просили дать более интересное задание, связанное со Scala. Вам предлагается написать
компонент `Boss` который ничего не умеет делать кроме как делегировать задания. Вам дан домен:

```scala
/** Успешный результат выполнения задачи
 * @param valueSize количество вэлью, которое приносит задача бизнесу
 */
case class TaskSuccess(valueSize: Int)

/** Неуспешный результат выполнения задачи message - оправдание, которым пользуется разработчик если задача не была
 * сделана.
 */
sealed trait TaskError {
  def message: String
}

object TaskError {

  /** Во время выполнения задачи возникли непреодолимые трудности
   */
  case class ResultError(message: String) extends TaskError

  /** Во время выполнения задачи возникли неожидаемые непреодолимые трудности
   */
  case class UnexpectedError(cause: Throwable) extends TaskError {
    override def message: String = cause.getMessage
  }

  /** Дедлайн прошел, задача перестала быть актуальной
   */
  case object Timeout extends TaskError {
    override val message = "timeout"
  }
}

type TaskResult = Either[TaskError, TaskSuccess]

/** Интерфейс для "ожидания" выполнения задачи
 */
trait Await[F[_]] {
  def get: F[TaskResult]
}

object Await {
  def apply[F[_]](f: F[TaskResult]): Await[F] = new Await[F] {
    override val get: F[TaskResult] = f
  }
}

trait Reporter[F[_]] {
  def start(task: Task[F]): F[Unit]

  def error(task: Task[F], err: TaskError): F[Unit]

  def success(task: Task[F], success: TaskSuccess): F[Unit]
}
```

За вас уже всё реализовали, вам осталось написать реализацию `Boss` для интерфейса:

```scala
trait Boss[F[_]] {
  def start(task: Task[F]): F[Await[F]]
}

object Boss {
  // Вам разрешается менять сигнатуру функции, но учтите что в тестах вы не сможете поменять вызов этой функции
  def make[F[_] : Reporter]: Resource[F, Boss[F]] = ???
}
```

* Необходимо реализовать инстанс `Boss`, который
    - может отдать задачу на выполнение с помощью `Boss.start` (при этом поток выполнения не должен блокироваться,
      вызов `Boss.start` не должен дожидаться результатов выполнения задачи)
    - задача должна начать выполняться **сразу** после вызова `Boss.start`
    - `Boss.start` возвращает `Await[F]`, вызов `Await.get` блокирует поток выполнения до тех пор, пока задача
      не будет выполнена
* Помимо того, что задача должна выполняться асинхронно, требуется:
    - печатать в консоль информацию о том, когда задача начала выполняться
    - печатать в консоль информацию о том, когда задача закончила выполняться / отменилась и тд с результатом задачи,
      текстом ошибки
    - если задача превышает максимальное время выполнения, необходимо отменять задачу, результат выполнения такой
      задачи должен быть `TaskError.Timeout`
    - если во время выполнении задачи произошла неожидаемая ошибка, то результат выполнения должен быть
      `TaskError.UnexpectedError`

  То есть, печать информации о процессе выполнения задач должен производиться **в консоль в ЛЮБОМ СЛУЧАЕ**

### Бонусное задание

Напомним, что на курсе действует система бонусных баллов (каждый бонусный балл - это абсолютный балл в системе БАРС); и
с этого ДЗ мы явно объявляем: что вы можете заработать бонусные баллы написав дополнительные тесты к ДЗ и получить

количество студентов у кого упали тесты, `total` - общее студентов, кто сдал ДЗ).

- Студентам кто уже сдал ДЗ, но у них упали доп тесты - необходимо исправить ДЗ (напомню, что вы всё ещё получаете 100%
  баллов за сдачу в срок дедлайн + 1 неделя);
- Тесты должны быть адекватные, и соответствовать заданию (за тесты вида `if (Random.nextInt() % 2 == 0) fail() else ok`

## Code Style:

Мы последовательно вводим список запрещенных механик, которыми нельзя пользоваться при написании кода, и рекомендаций по
code style. За нарушения мы оставляем за собой право **снижать оценку**.

* Переменные, классы и функции должны иметь осмысленные названия;
* Использовать `var` запрещается (используйте `val`);
* Использование `this` запрещается (используйте `self`, если надо);
* Использование `super` запрещается;
* Использование `null` запрещается (используйте `Option`);
* Использование `return` запрещается;
* Использование `System.<any function>` (например `System.exit`) запрещается;
* Использовать циклы запрещается (используйте `for comprehension`, `tailRec`, `tailRecM`);
* Использование java коллекций запрещается (используйте scala коллекции);
* Использование scala mutable коллекций запрещается (используйте scala immutable коллекции);
* Использовать `throw` запрещено;
* Использовать неявные преобразования запрещено;
* Касты или проверки на типы с помощью методов из Java вроде `asInstanceOf` запрещаются;
* Вызовы `usafe`, например `unsafeRunSync`;
* Вызов любых методов объекта `Await`;
* Вызов любых методов объекта `Async` (запрещён `Async` from/to `Future`);
