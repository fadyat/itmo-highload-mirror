## Задание 5

30 баллов

```
CREATE TABLE data(id INT PRIMARY KEY, n INT NOT NULL, a INT NOT NULL);
```

id - это сущности, n и a - некоторые показатели.

Если мысленно упорядочить записи по неубывнию n, то можно выделить периоды плавного неубывания.
Период плавного неубывания - это участок, на котором n не растет или растет на 1. Иногда период плавного неубывания
может иметь длину 1.

Например, в последовательности `2 2 3 5 5 7 8 9 10 12 20 25 26`  есть следующие периоды плавного неубывания:
`2 2 3`, `5 5`, `7 8 9, 10`, `12`, `20`, `25 26`.

Напишем запрос, который для каждого id покажет разницу между его показателем a и средним a по его и
следующему периоду плавного неубывания. То есть для `id`, чей `n` равен 7, мы возьмем среднее a по тем записям, чей
n равен 7, 8, 9, 10 и 12. Если следующего периода нет - берем только по текущему.
