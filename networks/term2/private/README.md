# Компьютерные сети

## Инструкция по настройке окружения

Для работы на курсе вам потребуется ноутбук с установленной операционной системой Linux. Мы рекомендуем использовать Ubuntu любой достаточно свежей версии, лучше LTS.

Зарегистрируйтесь в проверяющей системе https://networks.manytask.org/ . Пожалуйста, пишите имя и фамилию так, чтобы мы могли вас потом опознать. В идеале кириллицей. Секретный код вы можете найти в ЛМС.

Сгенерируйте ssh ключ и добавьте его в систему.
```
> ssh-keygen -N "" -f ~/.ssh/id_rsa - сгенерирует пару файлов id_rsa и id_rsa.pub. (Если у вас уже есть ключ, этот шаг не нужен).
```
Скопируйте содержимое файла id_rsa.pub (`cat ~/.ssh/id_rsa.pub`) в (https://gitlab.manytask.org/profile/keys)
Проверьте, что все работает. Должно быть так:
```
ssh git@gitlab.manytask.org
PTY allocation request failed on channel 0
Welcome to GitLab, Vasya Pupkin!
Connection to gitlab.manytask.org closed.
```

Когда вы заходите на курс в системе Manytask впервые, для вас создается клон репозитория с задачами. Взаимодействие с ним на курсе по базам данных осуществляется немного иначе, чем на других курсах. На нашем курсе вам нужно создать локальную копию репозитория и задать ей удаленное название student:

```
git clone git@gitlab.manytask.org:computer-networks/students-2025-spring/XXXXXXXXX.git -o student
```

Если в вашем нике есть точка, в url надо заменить их на `-`. Точную ссылку на ваш репозиторий можно найти на главной страница курса в Manytask (https://db1.manytask.org/), ссылка ``My Repo``.

Перейдите в папку репозитория.

Настройте git.

Сконфигурируйте автора коммитов в git
```
git config --global user.name "Vasya Pupkin"
git config --global user.email vasya@pupkin.ru
```

Если вы клонировали ваш репозиторий, не задав имя, вы всегда можете его переименовать его используя команду

```
git remote rename origin student
```

Теперь вы готовы сдавать задачи.

## Как сдавать задачи

Перейдите в папку с задачей, внимательно прочитайте условие - как делать задачу, как проверить что ваше решение правильное. Если вы считаете, что решение готово к отправке, запустите скрипт посылки из директории с задачей. `../submit.py`.

На главной странице курса в Manytask https://networks.manytask.org/ есть ссылка на список ваших посылок - Submits. Там вы можете следить за прогрессом последней посылки.

Проверьте, что оценка появилась в таблице с результатами, ссылка на которую также есть на https://networks.manytask.org/.

## Про задачи

Какие задачи доступны и какие дедлайны про ним можно прочитать либо на https://networks.manytask.org/, либо в .manytask.yaml в корне репозитория.

`test_infra` - это директория с скриптами для тестирования ваших решений, остальные директории в корне это задачи. Не стесняйтесь читать тесты и тестирующие скрипты. Если вам кажется, что чего-то не хватает, или можно сделать лучше, присылайте пул реквесты в [репозиторий курса](https://gitlab.manytask.org/computer-networks/public-2025-spring).


## Как запустить тесты локально

В корне репозитория есть скрипт `run-grader-localy.sh`. Запустите его передав переменную окружения `TASK_NAME`, например, так `TASK_NAME=static_routing ./run-grader-localy.sh`.

Чтобы все заработало, у вас должен быть [установлен docker](https://docs.docker.com/engine/install/) и собраны нужные Docker образы. 
Чтобы собрать докер образы запустите из корня репозитория `pushd test_infra/dockerfiles && ./build.sh && popd`.

Если что-то идет не так, пишите в чат курса.

## Обновление задачек по ходу семестра

По ходу семестра, мы будем обновлять задачи в [исходном репозитории курса](https://gitlab.manytask.org/computer-networks/public-2025-spring). Чтобы иметь возможность их получать, добавьте ссылку на этот общий репозиторий в вашу папку:

```
git remote add upstream git@gitlab.manytask.org:computer-networks/public-2025-spring.git
```

Теперь, чтобы обновить задачки, необходимо выполнять следующие команды из вашего локального репозитория:
```
git fetch --all
git stash
git pull upstream main
git stash pop
```

Если у вас что-то не получается, пишите свои вопросы в телеграм чат курса.

## Про политику оценивания

Если вы увидели прошедшие тесты и зачетнные баллы в manytask, то скорее всего, все хорошо.

Преподаватели оставляют за собой право прочитать ваше решения на предмет адекватности. Пример неадекватных вещей: целенаравленно пытаться обмануть тестирующу систему, списанные решения, отсутвие решения вовсе.

Если вы нашли тест, который вы считаете стоит добавить, напишите в чат. Если тест хорош, преподавтели могут выдать дополнительные баллы.
