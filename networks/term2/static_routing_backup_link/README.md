# Статическая маршрутизация с весами

Это задача продолжение задачи static_routing. Ваша задача настроить сеть так, чтобы даже в случае разрыва
одного любого линка между роутерами R1, R2, R3 в сети сохранялась полная связность.

Как и в прошлой задаче шаблон кода агента находится в файле `main.py`, ваша задача его закончить его имплементацию.

Во всех задачах можно предполагать, что интерфейсы описанные в топологии уже существуют, но никакая маршрутизация настроена не была.

## Отличия от задачи static routing

Единственное отличие - наличие дополнительных тестов с топологиями, где один линк разорван. Вам понадобится настройка [`metric`](https://man.archlinux.org/man/ip-route.8.en) в утилите `ip`.


## Подсказки

Все подсказки из предыдущей задачи применимы.

Так же заметьте, что на роутере R3 маршрут с минимальным приортетом до `192.168.1.1`(eth1 на R1) должен вести на R1, a до `192.168.1.2` (eth2 на R2) должен вести на R2. В первой задаче, можно было настраивать маршруты для всей сети ``192.168.1.0\24` целиком.
